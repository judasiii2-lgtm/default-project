# AGENTS.md - Normas de uso para los agentes

Este archivo define las normas de trabajo que los agentes deben seguir en este proyecto.

## Normas

### 1. Preguntar por commit y push al finalizar cada fase importante
Cada vez que terminemos una fase o paso importante del proyecto, el agente debe preguntar:
1. Si quiero crear un commit nuevo.
2. Si quiero subirlo a GitHub una vez acabado.

No hacer commit ni push automático sin confirmación explícita.
